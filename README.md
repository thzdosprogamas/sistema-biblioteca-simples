Este é um projeto em Python que simula um sistema básico de biblioteca.  
Ele permite realizar operações como:

- Cadastro de livros  
- Empréstimo de exemplares  
- Devolução de exemplares  
- Controle de estoque
- Este projeto foi desenvolvido com o intuito de praticar lógica de programação em Python e o uso de dicionários para manipulação de dados.
